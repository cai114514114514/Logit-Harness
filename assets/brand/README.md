# Logit- Harness identity

`loh-icon.png` is the blue L icon created with the built-in imagegen tool. The original generated
files remain in their generation directory. This workspace copy is the project asset and is included
in packaged releases.

The white geometric L has a diagonal right terminal suggesting forward motion. Use the full blue
tile as the app mark. The terminal uses a three-row blue block-character L beside the product,
model and project, similar in placement to Claude Code's startup mark. Its shape remains visible
without ANSI color. The CLI keeps success green and errors red; identity, selection and progress use blue.

- Icon blue: `#1459E8`.
- Dark terminal accent: `#5B9CFF`.
- Glyph: white.

Generation prompt (built-in tool, transparent background):

> Create a single uppercase geometric L for Logit- Harness, the coding agent with command loh.
> Equal-weight vertical stem and horizontal foot, crisp interior corner, softened outer corners,
> and a small diagonal cut on the far-right terminal. White L centered on an electric-blue rounded
> square, generous padding, readable at 24 pixels. Blue #1459E8 and #2878F0 with a very subtle tonal
> shift. Flat vector-like rendering. No perspective, 3D bevel, shadow, glow, texture, circuitry,
> extra symbols, wordmark, or mockup. Transparent outside the blue tile.

Final refinement prompt:

> Preserve the L, diagonal terminal, blue tile, placement and composition. Clean the rounded-square
> boundary and stray exterior pixels, retain transparent exterior and crisp antialiased edges.
