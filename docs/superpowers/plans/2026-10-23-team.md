# loh Multi-window Team Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver one persistent engineering team with independently interactive member windows, reliable collaboration and revision-aware acceptance.

**Architecture:** Extend the existing Session/Runner/Actor, SQLite journal and Unix IPC. Stable members own versioned assignments and addressed mail; clients select a public view of the same daemon. Keep guarded shared-tree writes and independent verification.

**Tech Stack:** Rust, Tokio, serde, rusqlite, crossterm/ratatui, macOS Terminal.

**Spec:** `docs/superpowers/specs/2026-10-23-team-design.md`

## Global Constraints

- Original worktree; no worktree creation, no sed, no V2/next names. Split by responsibility with readable code and comments explaining non-obvious invariants.
- Preserve untracked `docs/bug-review.md`, all unrelated state/user daemons, frozen research, credentials and the shared 50 RMB experiment ledger.
- Default two executing members; all use the configured DeepSeek model and shared budgets. Never call the paid provider during fixtures.
- Completion is current independent evidence, never a model final response.
- User approved implementation and in-tree work. No repeat approval gate. Do not push/publish new work unless already explicitly authorized for this delivery.

## Review Focus

- A window changes focus while a local asynchronous command or model reply is pending: preserve its original target and draft.
- A stopped/finished member receives old work or a user message after reassignment: reject stale intent, never steal work.
- Both members wait with no running job: detect cycles once without repeated paid diagnosis.
- A correction arrives between the verifier verdict and durable completion: atomically withhold completion.
- Members modify overlapping files or a user edits during cancellation: guard the whole patch and settle before handing ownership onward.
