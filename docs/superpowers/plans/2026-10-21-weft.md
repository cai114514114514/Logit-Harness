# Logit- Harness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Track checkboxes and actual evidence.

**Goal:** Deliver the complete approved Rust coding agent and evaluate its dynamic execution mechanism.

**Architecture:** A durable session runner owns workspace mutations and typed goal/evidence state.
The terminal is a detachable client. Tools and model transports have narrow interfaces; workers
propose work while one owner commits changes.

**Tech Stack:** Rust 2024, Tokio, reqwest, serde, SQLite WAL, Ratatui/Crossterm, Chromiumoxide, RMCP.

**Spec:** `docs/spec.md`.

## Review Focus

- New requirements arrive while an old command is writing: cancel, wait, reconcile before replacement.
- External edits invalidate a worker patch: reject it without overwriting the user.
- Crash between side effect and result persistence: reconcile; never blindly reexecute.
- Passing tests omit a requirement: independent completion gate remains closed.
- Long-lived services and detached clients must not deadlock or terminate task work unexpectedly.
