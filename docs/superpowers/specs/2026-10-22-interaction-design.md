# loh：轻量命令扩展与终端交互修正

本设计由用户于 2026-10-22 明确要求实施。保留 Rust 核心、DeepSeek Flash、蓝色 L、后台执行和动态纠偏。修复普通对话任务化、工具历史不可靠和命令不足。采用内置命令＋SKILL.md 工作流，复用 MCP，不增加插件运行时、市场或可替换执行内核。主界面使用终端原生滚动。

## 对话与任务

会话允许没有活动工程目标。问候直接回答，纯知识问答不读项目，项目问题按需只读；明确开发要求才建立目标、修改与验收。首轮实际响应判断如何处理输入，不固定多跑一次分类请求。项目指导、Skills 与目录发现延迟到确有需要，hello 的初始化也不能扫描项目。

自然语言可直接交代开发任务。/plan 保持只读直到用户明确要求实施，Skill 正文不能退出规划。每会话只有一个活动目标；独立新目标使用新的 ID，已完成目标的需求、动作和证据保留。纠正修订当前目标，运行中无关新任务先进入持久待办，只有明确替换才取消旧目标。普通回答结束等待输入，开发任务仍须独立验收，侧问不改变原目标或执行状态。

/new 立即开始新聊天，旧任务继续后台。同工作区的新开发任务保存输入并等待执行权，显示拥有者，在取得执行权前不启动工程模型或工作者。锁覆盖工程执行而非 daemon 的整个生命周期，所有源码写入结算后交接；源码只读的服务以独立输出目录单独管理。

## 命令

统一目录负责菜单、补全、帮助、参数和分发，显示来源与执行时机。本地命令不进入模型。保留既有 12 命令及语义，/resume 恢复执行，/sessions 切换会话。

新增 /new、/clear（/new 别名）、/rename、/export；/context、/compact、/usage；/plan、/goal、/tasks、/btw；/history、/tools、/copy；/skills、/mcp；/config、/permissions、/doctor。/init 和 /review 为随附 Skills。初始化保护已有指导文件；审查默认只读。

/config 修改已有非敏感默认值，对新任务生效；当前预算使用 /budget，密钥使用 /setup。/permissions 展示策略与具体待授权动作，复用 /approve，不新增规则编辑器。/tasks 查看并定位工作者、命令和服务，暂停/停止复用已有命令。/goal 无参查看，有参明确提交目标或需求变更。/plan 遇运行中修改，先取消并核对文件后进入只读。

/compact 等待工具配对结算，保留有效需求、用户纠正和未完成事项。/usage 显示已报告用量与 KV；/context 的字节估算与实际 token 区分，不虚构费用。/mcp 查看、重连和启停已配置服务，变更等当前调用结算后生效，结果不明保留原恢复流程。

技能通过 /<技能名> 参数调用，内置控制命令不能覆盖，同名技能选择来源，总能经 /skills 明确调用。参数是字面用户输入，无 Shell 插值。Markdown 不能注册代码、改变权限或预算。技能正文按需加载；浏览本地菜单不进入上下文。提示和工具顺序稳定，记录改变输入前缀的能力变更，不保证某个命中率。

## 历史

回合、模型响应和工具调用各有稳定标识；开始、增量、结果和取消归属于同一记录。实况与重放共用投影。结算块只向原生 scrollback 追加一次，局部刷新只画活动内容和输入；resize 不重播，同客户端重连按序号续接。

默认工具摘要与必要失败尾部，终端输出作原文；文件、搜索、补丁分别格式化。并发块按结算顺序追加并标明来源。/history 和 Ctrl+O 打开临时详情浏览器，支持分页、搜索、逐项展开和复制，关闭回到普通界面。完整可查询历史不受内存 300 条限制，截断明确标注。

新客户端显示最近 20 个结算块且最多 200 行，并有恢复标记，完整记录经 /history 查看。不承诺控制终端自身的原生回流和滚动位置。

## 验收

覆盖无扫描闲聊、纯知识与只读项目问答、开发与独立验收、目标切换及迟到结果、规划与后台并存、工作区等待恢复；覆盖并发/迟到工具输出、失败取消、重连、中文、resize 与 300 条以上历史；覆盖命令冲突、Markdown 字面参数、本地命令零模型调用、压缩后的需求和 KV 稳定前缀。

完整工程回归与实际 macOS PTY 验证后安装本机二进制，更新文档和证据。真实 Flash 小样本只使用既有 50 元共享账本，余额不足明确未验收；工程测试不替代真实模型质量，冻结研究版本保持不变。
