# 首轮研究结果：证据不足，尚未证明创新有效

2026-10-22，50 元共享预算的准入保护已停止新请求；已启动的会话均已结算并停止。
软件的工程验收通过，完整研究验收仍未完成。不能把下列小样本结果说成优于现有 harness。

## 保留集观察

每个条件仅有同一个任务的 3 次重复，不能代表其他任务或真实项目。

| 条件 | 外部通过 | 平均需求满足分数 | 代理独立完成 |
|---|---:|---:|---:|
| prompt | 3 / 3 | 1.000 | 0 / 3 |
| replan | 3 / 3 | 1.000 | 0 / 3 |
| tracking | 1 / 3 | 0.417 | 0 / 3 |
| dynamic | 3 / 3 | 1.000 | 0 / 3 |
| no_stagnation | 3 / 3 | 1.000 | 0 / 3 |

13 次运行因任务 token 余量不足以预留下一请求而结束，最后 2 次因共享资金准入不足而结束。
它们仍接受了外部检查，因此“外部通过”与“代理完成”分别报告。末尾资金不足的 tracking
运行甚至没有到达预设纠正触发点，不能把少收到一次脚本插话当作节省人工。

按预定规则，当前观察到的最强基线为 prompt（与 replan 并列后按既定次序选择）。dynamic
相对它的需求分数差为 0，脚本干预减少为 0%。只有一个配对任务，任务级置信区间不报告；
没有实际无效工作测量，也没有人类填完审阅表。阈值门槛未得到支持，研究结论保持
`not_established`。这些运行不能支持“减少 25% 人工或无效工作”的宣传。
